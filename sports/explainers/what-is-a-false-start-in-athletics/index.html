Athletics · Starting rules

What is a false start in athletics?

The short answer

A false start is an athlete beginning the race before the starter’s gun after taking a final starting position. In a crouch start, the rule looks at a movement that begins the start, such as losing contact with a hand or foot; a start system can flag a reaction under 0.100 seconds for officials to review. In an ordinary race, the athlete responsible is disqualified, with a special procedure for combined events.

A false start is not simply ‘moving before everyone else’. Under World Athletics Technical Rule 16.7, after an athlete has assumed a full and final starting position, they must wait for the report of the gun. In a crouch start, the start is commenced by a movement that includes or results in a hand or a foot losing contact with the ground or a footplate. A movement begun before the gun and continued into the start can also be judged a false start. The starter and start referee apply the rule to the circumstances they observe.

A certified start-information system can help. When it detects a reaction time below 0.100 seconds, it signals a possible false start to the officials. That threshold is a prompt to examine the available information, not a machine-only verdict that automatically disqualifies someone. The officials determine which athlete, if any, caused the false start. They can also conclude that no athlete was responsible—for example, if an external problem made the start unfair.

For ordinary track races, an athlete responsible for a false start is disqualified. If more than one athlete independently makes a false start, more than one can be disqualified; the rule does not mean the whole field must be punished for the first person’s action. When the start is not fair for a reason that is not an athlete’s false start, the starter can recall the field and restart without charging an athlete with a false start.

Combined events have a special first-false-start procedure. In the first false start of a combined-event race, the athlete responsible is warned and the other athletes are warned that a further false start will lead to disqualification. If another false start occurs, the athlete responsible is disqualified. This exception is why a rule explained as ‘one false start and you are out’ needs the context of the event.

Not every movement in the blocks is a false start. For example, if an athlete moves their hips but keeps their hands and feet in contact with the ground and blocks, that movement alone does not meet the rule’s definition of commencing the start. It may still be treated as improper conduct if the athlete repeatedly disrupts the start. Officials distinguish that conduct from a false start because the penalties and the fairness issue are different.

The practical lesson for a runner is to settle into the final position, keep still and react to the gun rather than anticipate it. For spectators, a displayed reaction time is useful context but should not be treated as the entire decision. The starter’s ruling follows the rule and all available evidence, including the start system when one is in use.

In practice

In a 100m final, an athlete reacts so quickly that the start system signals a possible reaction below 0.100 seconds. The race is recalled. The starter reviews the system and other evidence and decides whether the athlete began before the gun. If the athlete is responsible, they are disqualified under the ordinary sprint procedure; if the system signal was not a false start, the race can restart without that penalty.

Common misunderstandings

  • A reaction below 0.100 seconds is an automatic disqualification. The system signals a possible false start. Officials use that signal and other evidence to decide responsibility under the rule.
  • Any twitch before the gun is a false start. The rule defines when an athlete has commenced the start. Some movement that does not begin the start may instead be a conduct issue.
  • The whole field gets one false start before anyone is out. In ordinary races, the responsible athlete is disqualified. Combined events use a distinct warning procedure for the first false start.

Quick questions

Is 0.100 seconds the rule for every false start?

No. It is the signal threshold used by a certified start-information system to flag a possible false start. The officials make the decision under the rule.

What happens after a false start in a normal sprint?

The athlete judged responsible is disqualified. Combined events have a special warning procedure for the first false start.

Can a race be recalled without a false-start disqualification?

Yes. A start can be aborted or recalled because it was not fair or an external issue intervened; that is distinct from charging an athlete with a false start.
