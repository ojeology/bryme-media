# BRYME / nextclip — Upgrade summary

**Status:** Committed and pushed to `ojeology/nextclip` (`main`, commit `80dc3d4c91`).
**Canonical live host:** `https://bryme.onrender.com` — deploy the latest push to make it live.

---

## What changed

### 1. Dark / Light theme toggle (new)
- A **theme toggle button** now sits in the site header.
- **Dark is the default** and respects the visitor's system preference.
- Choosing a theme is **saved in `localStorage`** so it persists across pages/visits.
- In light mode, the page canvas and content surfaces flip to a clean light
  palette while the cinematic full-bleed banners (hero carousel, movie hero,
  sports feature, footer, mobile bar) stay dark — a deliberate "dark components
  on light" look.

### 2. Reading progress bar
A thin 4-colour gradient bar along the top of the page shows scroll progress.

### 3. Back-to-top button
A floating button (bottom-right) appears after scrolling, smoothly returns to top.

### 4. Keyboard shortcut
Press **`/`** anywhere to jump straight into Search (or the homepage
"Recommend for me" box) without touching the mouse.

### 5. Accessibility
- Visible `:focus-visible` outlines on links, buttons, inputs and selects for
  keyboard users.
- `theme-color` and `color-scheme` hints update with the active theme.

### 6. Performance & SEO
- **Preconnect** hints to `i.ytimg.com` and YouTube so posters/trailers load faster.
- New **favicon** (SVG + PNG) and **apple-touch-icon**.
- **PWA manifest icons** (192, 512, maskable) and a `manifest` link added.
- `theme-color` meta tag.

## Files changed (source)

- `manifest.webmanifest` — icons + theme colours.
- New: `assets/favicon.svg`, `assets/favicon.png`, `assets/icons/*`.
- All 880+ generated pages rebuilt (they now carry the new head tags).
